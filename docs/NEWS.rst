Release history
===============

Geomodels 1.0.1 (21/09/2026)
----------------------------

* Update vendored GeographicLib to v2.7.
* Drop support for Python older than v3.11.
* Move ``tests`` folder out of the package directory.
* Use robust regular expression for paths in the unit tests.
  Tests on MS Windows no longer fail when the ``GEOGRAPHICLIB_DATA``
  path is a relative path.
